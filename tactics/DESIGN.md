# 星砕きの戦旗(STARFALL TACTICS)— 設計書

ファイアーエムブレム / FFT 風の、マス目盤面を動かすターン制の戦略RPG。
ブラウザで1ファイル(`dist/tactics.html`)を開けば遊べる。スマホのタッチにも対応する。
キャラの絵は外部の無料素材(CC0)を使う(`assets/CREDITS.md`)。

## 技術
- 素の JavaScript + Canvas 2D。ライブラリは使わない。
- `build.py` が `src/*.js` を決まった順に連結し、`assets/*.png` を base64 で埋め込んで `dist/tactics.html` を作る。テスト用に `<html>` 付きの `test/index.html` も作る。
- 論理解像度は 320x240(16pxのタイルを 20x15)。整数倍で拡大し、`image-rendering: pixelated` を使う。
- 乱数は `rnd()`(シード固定可、`?seed=` / `window.__tac.seed(n)`)。
- テスト用フックは `window.__tac`(状態の取得、入力の送信)。

## ゲームの流れ
タイトル → 章ごとに「会話(顔グラ付き)→ 戦闘マップ → 勝利会話」→ 次の章 → エンディング。
最低3章。第3章はボス戦。セーブは localStorage(章の開始時に自動保存)。

## 戦闘ルール
- **フェーズ制**: 自軍フェーズでは、各ユニットを好きな順に1回ずつ「移動 → 行動(攻撃 / 杖 / 待機)」させる。全員が行動するか「ターン終了」を選ぶと敵軍フェーズに移る。
- **移動**: 移動力 MOV。地形ごとに移動コストがかかる。範囲は BFS で求める。敵ユニットのいるマスは通れない。味方のいるマスは通れるが、止まれない。
- **地形**: 草原(コスト1)、道(1)、森(2・回避+20・防御+1)、山(3・回避+30・防御+2。騎兵は通れない)、水(通れない)、砦(1・回避+20・防御+2・ターン開始時にHPを20%回復)。
- **ステータス**: HP / 力 / 魔力 / 技 / 速さ / 守備 / 魔防 / 移動。
  - 物理ダメージ = 力 + 武器威力 − (守備 + 地形防御)
  - 魔法ダメージ = 魔力 + 威力 − 魔防
  - 命中 = 武器命中 + 技×2 − (敵の速さ×2 + 地形回避)。クランプする。
  - 速さが 4 以上上回ると2回攻撃。
  - 反撃: 攻撃された側は、射程が届けば反撃する。
- **射程**: 剣・槍・斧は1、弓は2、魔法は1〜2、杖(回復)は隣接1。
- **兵種**(自軍5人)
  - ナイト(槍、重装、MOV4、高守備)
  - アーチャー(弓、MOV5、射程2、反撃は射程2のみ)
  - メイジ(魔法、MOV5)
  - ヒーラー(杖で回復、MOV5、自分では攻撃しない)
  - シーフ(剣、MOV6、速い)
- **経験値とレベル**: 攻撃で+10、撃破で+30、回復で+15。100でレベルアップし、成長率(%)ごとに能力が上がる。章をまたいで引き継ぐ。
- **敵AI**: 攻撃できる対象の中から「与えるダメージ − 受ける反撃」が最大のものを選ぶ。届かなければ一番近い自軍へ向かって移動する。待機型(ボスなど)は射程内に入るまで動かない。
- **勝利条件**: 敵全滅、またはボス撃破。**敗北条件**: 主人公(ナイト「レオン」)のロスト、または全滅。敗北したら章をやり直す。

## 操作
- キーボード: 矢印=カーソル、Z/Enter=決定、X/Esc=キャンセル、A=ユニット情報、E=ターン終了メニュー。
- タッチ / マウス: マスをタップすると、カーソルの移動と決定を同時に行う。画面外のボタンで「キャンセル」「ターン終了」。
- 戦闘予測ウィンドウ: 攻撃対象を選ぶと「ダメージ・命中率・2回攻撃」を双方分表示し、決定で実行する。
- 攻撃演出: ユニットが相手側へ少し踏み込み、ダメージ数字を出し、HPバーが減る(ゲーム画面上でそのまま見せる)。

## 画面
- 盤面: タイルを描き、移動範囲は青、攻撃範囲は赤の半透明で塗る。
- ユニット: 4方向の歩きアニメ。行動済みは灰色にする。足元に小さなHPバーを出す。
- 自軍は青系、敵軍は赤系の足元マーカーで区別する。
- 上部: 「ターンN 自軍フェーズ」。フェーズ切り替え時は帯のテロップを出す。
- 下部: カーソル下のユニット情報(顔グラ、名前、HP)と地形情報。

## 音
WebAudio の簡単なチップチューン(BGM 1〜2曲)と効果音(決定・攻撃・回復・撃破)。外部の音ファイルは使わない。

## テスト(Playwright、`tactics/test/`)
- `smoke.js`: 起動してタイトルが出て、エラーが無いこと。
- `play.js`: ボット(敵AIと同じロジックで自軍を操作)が実際の入力で全章をクリアし、エンディングに到達すること。
- `shots.js`: 主要な場面のスクショを `tactics/test-out/` に保存する(レビュー用)。
