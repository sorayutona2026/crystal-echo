# 星砕きの戦旗(STARFALL TACTICS)

ファイアーエムブレム風のマス目ターン制戦略RPG。素の JavaScript + Canvas 2D で作った単一HTMLのゲームです。
絵は CC0 のドット絵素材(`assets/CREDITS.md`)、音楽と効果音は WebAudio でコード生成。仕様は `DESIGN.md`。

## 遊ぶ・ビルド
```
cd tactics
python3 build.py            # dist/tactics.html と test/index.html を生成
```
- `test/index.html` をブラウザで開けば遊べます(`<html>` 付きの完全なページ)。
- `dist/tactics.html` は Artifact などに貼る用(`<html>` タグ無しの断片、画像も全部埋め込み)。
- `?seed=123` を付けると乱数(命中判定・成長)を固定できます。

## 操作
| 入力 | 動作 |
|---|---|
| 矢印キー | カーソル移動 / メニュー選択 / 攻撃対象の切り替え |
| Z / Enter / Space | 決定 |
| X / Esc / 右クリック | キャンセル(移動を取り消して元の位置に戻す) |
| A | ユニット詳細(能力値)の表示切り替え |
| E | ターン終了メニュー |
| M | 音の ON/OFF |
| タッチ・マウス | マスをタップ = カーソル移動と決定を同時に行う。メニューの行・予測ウィンドウもタップ可。画面外ボタン「キャンセル」「情報」「ターン終了」「音」 |

画面は縦・横どちらのスマホでも、PC でも、ウィンドウに合わせて拡大されます(2倍以上は整数倍)。

## ルール早見表
- **フェーズ制**: 自軍フェーズで各ユニットが「移動 → 行動(攻撃/回復/待機)」を1回ずつ。全員が行動するか「ターン終了」で敵軍フェーズへ。
- **移動**: 青い範囲が移動範囲(地形コスト付き BFS)。敵は通れない、味方は通れるが止まれない。赤い範囲は攻撃が届くマス。
- **地形**: 草原/道(コスト1)、森(2・回避+20・守備+1)、山(3・回避+30・守備+2)、水(通行不可)、砦(1・回避+20・守備+2・自軍/敵軍フェーズ開始時にHP20%回復)。
- **ダメージ**: 物理 = 力 + 武器威力 − (守備 + 地形守備)、魔法 = 魔力 + 威力 − 魔防。
  命中 = 武器命中 + 技×2 − (相手の速さ×2 + 地形回避)。速さが相手より4以上高いと2回攻撃。
- **射程**: 剣・槍・斧は1、弓は2のみ、魔法は1〜2、杖は隣接1。射程が届けば攻撃された側は反撃する。
- **経験値**: 攻撃(反撃を受けた場合も)+10、撃破+30、回復+15、章クリアで全員+40。100でレベルアップ(成長率で能力が上がる)。章をまたいで引き継ぎ。武器は章ごとに強化(鉄→鋼→銀)。
- **敵AI**: 攻撃できる相手のうち「与えるダメージ − 受ける反撃」が最大のものを選ぶ。届かなければ最寄りの自軍へ接近。`wait` は射程に入るまで待機、`hold`(ボス)は動かず射程内だけ攻撃。
- **勝敗(章ごとに違う)**: 殲滅(第1章)/ 防衛(第2章: 8ターン持ちこたえる。敵に村のマスを踏まれると敗北)/ 脱出(第3章: 生きている全員が出口マスで「離脱」)/ ボス撃破(第4〜6章)。レオンが倒れるか全滅すると敗北(章をやり直す、または野営地で整えてから)。画面上部に目的とターン数を表示。
- **負傷**: 戦闘で倒れた仲間は「負傷」になり、次の章は休む(レオンは倒れたら敗北なので対象外)。
- **野営地**: 章のあいだに開く。ゴールドは撃破・宝箱・章クリアで入り、ショップ(鉄/鋼/銀と特別武器、傷薬)・鍛冶(+1ずつ、最大+3)・スキル選択(Lv5/Lv10)・クラスチェンジ(Lv10と勇者の証)・支援会話・出撃準備(人数は章ごとに上限)・セーブがある。「おまかせで整える」で自動整備もできる。
- **絆**: 自軍フェーズの終わりに、行動した味方どうしが隣り合っていると絆が1たまる。C/B/A で隣り合ったとき 命中・回避・必殺 が上がる(ユニットの上にハート)。会話は野営地で見られる(5組×3)。
- **必殺**: 必殺率(技/4+武器+スキル+絆)で3倍ダメージ。
- **戦闘中の会話**: 各章に2〜3個。隣り合ったとき、または特定のターンの開始時に起きる。第2章はレオンがジンの隣で「話す」と仲間になる。

## 登場人物
レオン(ナイト・主人公)/ ミラ(アーチャー)/ 老魔道士ルカ(メイジ)/ ソフィア(ヒーラー・2章から)/ ジン(シーフ・2章から)。敵は ゴブリン・スライム・スケルトン・ダークメイジ・金角将軍ガルド。

## ファイル構成
```
tactics/
  build.py            src/*.js を連結し assets/*.png を base64 で埋め込む
  src/
    shell.html        ページ枠・CSS・キャンバス・画面外ボタン
    engine.js         キャンバス拡大(fit)、入力、乱数 rnd()、ジェネレータのスケジューラ Co、描画ヘルパ
    assets.js         画像の読み込み、地形タイル合成、スプライト(グレー/白フラッシュ版)、顔グラ、砦の描画
    audio.js          WebAudio のチップチューンBGM(タイトル/自軍/敵軍/ボス/勝利/敗北/エンディング)と効果音
    data.js           地形・武器アイテム・スキル・クラスチェンジ・絆・仲間・敵
  story.js          全6章(マップ、敵配置、目的、会話、戦闘中の会話)、支援会話15本、エピローグ
  camp.js           野営地のルール(ショップ・鍛冶・スキル・クラスチェンジ・出撃・おまかせ整備)※DOM非依存
  base.js           野営地の画面(大きなタップ行)と進行
    battle.js         ルール本体(BFS移動、射程、予測、戦闘、経験値、勝敗) ※DOM非依存
    ai.js             敵AIと、テストボット用の自軍行動提案 suggestAction ※DOM非依存
    ui.js             描画(マップ、ユニット、パネル、予測ウィンドウ、レベルアップ、会話、各シーン)
    main.js           シーン進行、入力処理、戦闘演出(歩き・突進・ダメージ数字)、ループ、window.__tac
  assets/             素材PNG、manifest.json、CREDITS.md
  test/
    lib.js            Playwright 起動の共通処理(リポジトリ直下の node_modules を使う)
    bot.js            キーボード入力でプレイするボットの部品
    smoke.js          起動・タイトル表示・第1章開始・コンソールエラー無しの確認
    play.js           ボットが全章をクリアしてエンディングへ(`SEED=1 node test/play.js`)
    touch.js          スマホ縦横での実タップ操作・ボタンのはみ出し確認
    shots.js          スクリーンショットを test-out/ に保存
    sim.js            ブラウザ無しの高速バランス計算(野営地の自動整備つき、`node test/sim.js 100`)
```

## テスト
リポジトリ直下に `node_modules/playwright` が必要です(`npm install`)。Chromium は設定済みのものを使います。
```
python3 build.py
node test/smoke.js
SEED=1 node test/play.js     # COMPLETE と出れば成功。SEED=2, 3 も通ること
node test/touch.js
node test/shots.js           # test-out/*.png
node test/sim.js 60          # バランス確認(章ごとの勝率・平均レベル)
```
`play.js` は `window.__tac.suggest()`(敵AIと同じ評価で自軍の行動を提案)を読み、カーソル移動・決定をすべて `page.keyboard` で送ります。
テスト用フック: `__tac.state()`(状態)、`__tac.suggest()`、`__tac.seed(n)`、`__tac.speed(n)`(固定ステップ倍速)、`__tac.start(章番号 | 'ending')`、`__tac.setExp(id, n)`。

## イラスト素材(ChatGPT 生成)
- 原本: `art-src/gpt_faces_sheet.png`(顔グラ10枚)、`art-src/gpt_units_sheet.png`(全身10体)。ゲームには埋め込まない。
- `python3 tools/prep_gpt_art.py` が顔を256x256に切り出し、全身は連結成分で切り分けて影・赤黄のふちを除去し、`assets/gpt/*.webp` に書き出す(`assets/gpt/contact.png` で目視確認)。
- 描画は `src/hd.js` の高解像度オーバーレイ(`#cvh`)で行い、ドット絵のバッファを通さない。顔グラ(会話・情報欄・レベルアップ)、タイトルの5人、攻撃カットイン、ガルド登場演出、縦持ちのマップ上ユニットに使う。
- メニュー(Eキー)で「戦闘アニメ ON/OFF」「表示 自動/イラスト/ドット」を切り替えられる(localStorage に保存)。カットインはタップで飛ばせ、オート x2 では省略される。
