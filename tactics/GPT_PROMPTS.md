# ChatGPT 画像生成プロンプト(星砕きの戦旗)

作る絵は2種類です。

- **A. 顔グラ**:会話や情報欄に出る胸像。いちばん効果が大きいので、まずこちらから作るのがおすすめです。
- **B. 盤面キャラ**:マップ上を歩く小さなドット絵。

## コツ
1. 新しいチャットを開き、最初に「共通スタイル」を貼ります。そのあと1キャラずつ頼むと、絵柄がそろいやすくなります。
2. 気に入った1枚ができたら、次からは「さっきと同じ絵柄で」と付け足します。
3. 保存したら、ファイル名を下の表のとおりに変えて、このチャットに貼ってください。組み込みは私がやります。

---

## A. 顔グラ(会話・情報欄用)

### 共通スタイル(最初に1回貼る)
```
これからファンタジー戦略RPGの会話用の顔グラフィックを何枚か作ります。全員、次のルールで統一してください。
- 絵柄:日本のSRPG(ファイアーエムブレムやタクティクスオウガ)風のアニメ調イラスト。くっきりした線画、セル塗り(影は2段)、少し落ち着いた中世ファンタジーの色合い
- 構図:正方形 1024x1024。胸から上のバストアップ。体はやや右向き(3/4)、顔はこちらを見る
- 背景:単色のうすいグレー(#d8d8d8)。模様・文字・枠・サインは入れない
- 1枚に1人だけ。表情ははっきり
```

## B. 盤面キャラ(マップ上のユニット)

マス目は小さいので、遠くからでも誰か分かるように、はっきりした色とシルエットにします。左右の向きはコードで反転して作ります。

### 共通スタイル
```
SRPGのマップ上を歩く小さなユニットのドット絵を作ります。全員次のルールで統一してください。
- 2.5頭身くらいのちびキャラ、正面よりやや左を向いて立つ全身
- ドット絵(ピクセルアート)。くっきりした黒っぽい輪郭線、色数は少なめ、ぼかし・グラデーションなし
- 正方形 1024x1024 に、キャラを中央に大きく(画面の8割の高さ)
- 背景は完全な透明。透明にできなければ真っ白(#ffffff)の単色
- 影・地面・文字は描かない。1枚に1体だけ
```

## 送るときのメモ
- 顔グラは A だけでも十分見違えます。B は、A に満足してから作れば大丈夫です。
- 画像はこのチャットにまとめて貼ってください。私が `tactics/assets/gpt/` に入れて、ゲームに組み込みます。顔グラは会話枠に合わせて切り抜き、盤面キャラは背景を抜いて縮小します。
- 一部のキャラだけでも組み込めます。無いキャラは今の CC0 の絵のままになります。
