# ねむりの迷宮(NEMURI NO MEIKYU)

トルネコ風(不思議のダンジョン系)のローグライク。クリスタル・エコーとは別の作品で、描画・入力・音の土台(`engine.js` / `audio.js` / `shell.html`)だけを流用している。
外部素材なし。ドット絵・音楽・効果音はすべてコードで生成し、ビルドすると1ファイルのHTMLになる。企画は `DESIGN.md`。

**いまの範囲(段取り1: 遊べる土台)**: おもちゃの森 1〜10F。迷宮の自動生成、8方向移動、視界(部屋は全体が見え、通路は周囲1マス)、ミニマップ、階段、まどろみ度(満腹度)、悪夢6種、攻撃・レベルアップ、簡単な持ち物(菓子・キャンディ・ほしのかけら)。

## 遊ぶ・ビルド
```
cd mystery
python3 build.py      # dist/nemuri.html(Artifact用、<html>無し)と test/index.html(ブラウザで開く用)を作る
```

## 操作
| 入力 | 動作 |
|---|---|
| 矢印 / WASD | 移動(2つ同時押しで斜め。テンキー 7/9/1/3、Home/PgUp/End/PgDn でも斜め) |
| Z / Enter(攻撃ボタン) | 向いている方向へ攻撃(空振りでも1ターン)/ メニューの決定 |
| X(足踏みボタン) | 短く押す = 足踏み(1ターン休む)。押したまま方向 = 向きだけ変える。長押し = 足踏みを続ける / メニューで戻る |
| C / Esc(道具ボタン) | メニュー(道具・足元・ステータス・マップ表示) |
| スマホ | 画面に指を置いた場所がスティックになり、ドラッグした方向(8方向)へ歩く。短いタップは攻撃。メニューの行は直接タップできる |

## ルール
- 1回動くと敵も1回動く(チクタクワニは2回)。壁の角をまたいだ斜め移動・斜め攻撃はできない。
- **まどろみ度**(満腹度にあたる): 10ターンで1減り、0になると毎ターンHPが1減る。ゆめの菓子で回復する。
- HPは歩いているだけで少しずつ回復する。レベルは潜るたびに1から。倒れると夢から追い出され、持ち物は消える。
- 新しい敵が見えたら、歩き続けていても一度止まる(方向を離すと再開)。

## ソース構成(src/、build.py がこの順に連結する)
| ファイル | 役割 |
|---|---|
| shell.html | ページの外枠(画面・タッチ用ボタン・CSS)。クリスタル・エコーから流用し、色とボタン名を変更 |
| engine.js | 描画の基盤(256x224を3倍、大きなPC画面では4倍)、`fit()`、入力(8方向。`Input.vec()` が [dx,dy] を返す)、スワイプのスティック、タップ対象 `Touch`、ウィンドウ・カーソル・ゲージ、`Store` |
| audio.js | WebAudio のチップチューン。曲 `TRACKS`(title / dream1〜3 / gameover / clear)と効果音 |
| art.js | 16pxタイル(テーマ3種 `THEMES`: 夕暮れ・月夜・深い夢)、主人公ハル(パジャマとナイトキャップ)、悪夢 `MON_DRAW`、アイテム `ITEM_DRAW` |
| data.js | 悪夢 `MONSTERS`(出る階・強さ・特殊能力)、アイテム `ITEMS`、経験値表、序章の文 |
| dungeon.js | 階の生成 `genFloor`(3x3区画に部屋または通路の分岐点を置き、全域木+αでつなぐ。まれに大部屋)、視界 `updateFov`、斜めの角ルール `canStep`、距離場 `distField`(BFS) |
| game.js | 状態 `G`、行動(ジェネレータ。`yield n` で nフレーム待つ)、ターン終了処理(まどろみ・回復・敵の行動・湧き)、敵AI(見えたら追う/見失ったら少し追う/普段は別の部屋へ歩く/カミナリぐもは直線上なら遠距離攻撃) |
| ui.js | 迷宮の描画、HUD、ミニマップ、メッセージ、メニュー、タイトル・序章・ゲームオーバー・クリア |
| main.js | メインループ(60fps固定)、起動、テスト用フック `window.__nm` |

## テスト(リポジトリ直下で `npm install` 済みであること)
- `node test/play.js` … ボットが1Fから10Fまで実際の入力(方向キー・A・B・メニュー)で通しプレイし、CLEAR になるか確認(`SEED=n`、`RUNS=20` で複数シードの到達階と勝率)。ボットのクリア率は約9割
- `node test/smoke.js` … 起動・序章・歩行・メニュー・足踏み
- `node test/touch.js` … 実際のタッチで、タップ開始・8方向ドラッグ歩行・攻撃/足踏み/道具ボタン・メニュー行のタップ
- `node test/layout.js` … 縦持ち・横持ちのスマホとPCで画面とボタンがはみ出さないか
- `node test/shots.js` … テーマ別の画面・ゲームオーバー・クリアのスクリーンショットを `test-out/mystery/` に保存
- 変更後は `python3 build.py` → `node test/play.js` で CLEAR になることを確認する
