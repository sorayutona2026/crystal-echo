# ねむりの迷宮 企画書

## 物語(軽め)
妹のノアが原因不明の眠りから覚めない。兄のハルは、祖母が遺した「夢わたりの枕」で妹の夢へ入る。
夢の奥ほど、ノアが怖がっていたもの・忘れたかったものが悪夢(モンスター)として現れる。最深部には眠りの原因の「いちばん怖い夢」がいる。
会話は序盤・町の発展・エンディング程度。切ないが、最後は目覚めて終わる。

## 前半はかわいく、後半からホラー(『クリムゾンの迷宮』風)
『クリムゾンの迷宮』からは、遊びの骨組み(ゲーム機の指示・ルート選択・ほかの参加者との奪い合い・食料の欠乏・食べると変わってしまう恐怖)と赤い荒野の雰囲気だけを借りる。物語・人物・文章は借りない。
- **転換点**: おもちゃの森を抜けると、森の出口にノアの**携帯ゲーム機**が落ちている。拾うと画面がつき、「ゲームを はじめます」という一文が出る。そこから夢の色が少しずつ赤く染まり、BGMも音数が減っていく。
- **あかい荒野**(本編25F): 赤い岩の谷が続く迷宮。
  - **ゲーム機の指示**: 階ごとに短い文が届く(例「つぎのチェックポイントは 北」「たべものは 西に ある」)。嘘が混じることがあり、「情報」の道を選ぶほど正確になる。
  - **チェックポイントのルート選択**(5階ごと): 4つの道から1つを選ぶ。**生きのびる道具**(クレヨン・びん)/**身を守る道具**(武器・盾)/**情報**(地図・識別・ゲーム機の精度)/**食料**(お菓子・水)。選んだ道によって、その先の階に落ちている物が偏る。
  - **ほかの子どもたち**: 同じ夢に迷い込んだ子が4〜5人いて、同じ階を進んでいる(名前と性格つき)。出会うと、取引・道具の交換・一緒に戦うことができる。ただ、空腹が進むとこちらの持ち物を奪いに来ることもある。
  - **あかい菓子**: よく似た未識別の菓子。まどろみ度は大きく回復するが、食べた子は**ユメクイ**(悪夢に飲まれた子)になり、追ってくる側に回る。ハル自身も食べると、一定のターン、視界が赤く狭まる。識別の仕組みが生死を分ける。
  - **のどのかわき**: 荒野だけの2本目のゲージ。泉や水筒で回復する。まどろみ度と合わせて、物資が足りない状態が続く。
  - **だれかが見ている**: 同じ階に長くいると「見張り」(倒せない強い悪夢)が近づいてくる。足音と画面の端の気配で知らせる。
- **怖がらせ方**: 血や残酷な描写は出さない。暗さ、音が減ること、追われること、画面の外にいる気配、色が赤くなっていくことで怖がらせる。
- **種明かし**: ゲーム機の「ゲームマスター」こそが、ノアを眠らせている「いちばん怖い夢」。最後は、ほかの子たちと一緒にゲームを終わらせて目覚める(テーマ: 一人で抱え込んだ恐怖を、だれかと分け合って終わらせる)。

## ローグライクのルールと夢の理由づけ
| 本家 | この作品 |
|---|---|
| 潜るたびに形が変わる | 夢だから毎回ちがう |
| 毎回レベル1 | 目覚めると夢の中の力は消える |
| 倒れると持ち物を失う | 夢から追い出され、持ち物は夢に溶ける |
| 満腹度 | まどろみ度(夢にいられる残り時間)。0で目覚めかけ、HPが減る。「ゆめの菓子」で回復 |
| 倉庫 | 枕元の宝物箱。ここに入れた物は消えない |

## アイテム(本家準拠の効果、子どもの夢らしい見た目)
- 草 → キャンディ(未識別は色の名前)/ 巻物 → 絵本のページ / 杖 → クレヨン(描いた線が飛んで効く)
- 壺 → びん・おもちゃ箱 / 武器・盾(木の剣・ほうき・なべのふた・図鑑の盾、修正値と印、合成)/ 腕輪 → リボン・ヘアピン
- すべてのアイテムは投げられる

## 悪夢(約40種、特殊能力が主役)
カミナリぐも(遠距離)、おばけ毛布(眠り)、チクタクワニ(倍速)、イジワルかげ(盗んでワープ)、ちゅうしゃバチ(最大HP低下)、まいごの声(仲間を呼ぶ)、カガミ(分裂)、くらやみ(壁抜け)など。

## 迷宮
1. おもちゃの森(10F、持ち込み可)… チュートリアル。かわいい夢
2. あかい荒野(25F、本編)… 後半のホラー。ゲーム機・ルート選択・ほかの子ども・ユメクイ。ボス「いちばん怖い夢」(ゲームマスター)
3. ノアの見たくない夢(50F、持ち込み不可・全部未識別)… クリア後

## 拠点「まどろみの町」
ぬいぐるみの住人が店・宝物箱(倉庫)・鍛冶屋(合成)・語り部(ヒント)を営む。ノアの記憶を取り戻すたびに住人と施設が増える。

## 仲間
敵を仲間にする仕組みは入れない(一人で潜る)。あかい荒野の「ほかの子どもたち」は仲間ではなく、自分の考えで動くNPC(一時的に一緒に戦うことはある)。

## 段取り
1. **土台**(済): 迷宮生成・移動・視界・ミニマップ・階段・まどろみ度・悪夢6種・攻撃とレベルアップ
2. 持ち物と識別(キャンディ・絵本のページ)、投げる
3. 装備・クレヨン・びん・ワナ、悪夢20種と特殊能力
4. まどろみの町(店・宝物箱・合成)、倒れた時の処理、中断セーブ
5. **あかい荒野**: ゲーム機の指示、チェックポイントのルート選択、ほかの子どもたち(NPC)、あかい菓子とユメクイ、のどのかわき、見張り、赤く染まる演出
6. 迷宮3つの仕上げ、モンスターハウス、店泥棒、残りの悪夢
7. 物語イベント(転換点・種明かし・エンディング)、BGM・効果音、バランス調整
